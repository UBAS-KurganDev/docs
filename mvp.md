Когда ты планируешь путешествие, тебе приходится тратить много времени для того, чтобы найти выгодные авиабилеты. Авиасейлз и другие аггрегаторы помогают найти билеты с пересадками, либо очень дорогие прямые билеты. А что если ты не сильно ограничен во времени путешествия и можешь задержаться на пересадке? Например, брать отдельные билеты, оставаться на пару дней погулять в Алматы, Дубае или Ташкенте по пути в Токио?

Суть проекта в том, чтобы помочь выгодно спланировать путешествие из точки A в точку C с возможностью стать туристом в точке B (с единым билетом/разными – без разницы). Для тех путешественников, которые любят риск.

Основная аудитория MVP — пользователи из РФ, планирующие отпуск с дальним путешествием. Человек знает откуда и куда он двигается, при этом готов потратить до 3 дней в месте пересадки, при достаточной туристической ценности места пересадки.

Базовый пользовательский сценарий, который закрывает MVP: у пользователя есть желание добраться из города A в город B с возможной пересадкой в городе C. Пользователь указывает период времени в двух датах, в который он хочет совершить перелёт.
Система строит и предлагает пользователю несколько вариантов маршрута с пересадкой. При это учитывается, чтобы в пересадке было больше дневного времени, чем ночного. Учитывается туристическая привлекательность города на пересадке, при этом учитывается и включается стоимость визы для граждан РФ.

В MVP нет авторизации, нет возможности купить билеты, только получить информацию о рейсе, на который нужно купить билет. Не учитывается проживание, почти всегда пользователь сможет без проблем найти жильё с помощью стороннего сервиса.
